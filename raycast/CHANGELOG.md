# Nidus Changelog

## [Initial Version] - 2026-07-09

- Replaced the scaffold form with a project-first Inbox capture flow.
- Added fuzzy project and discipline search.
- Added instant `alias + space` project entry.
- Added shared project aliases in `_routing/project-aliases.json`.
- Added `Title -- optional note` capture grammar.
- Added `t- Title -- optional note` for undated tasks in the primary Task Manager.
- Added a persistent syntax guide and an Inbox/Task destination selector for guided capture.
- Made spaces optional after the `t-` task prefix and `--` note separator.
- Added automatic vault discovery with a manual preference fallback.
- Added atomic card writes compatible with Nidus's native Card format.
